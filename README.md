# Neon English — Квест-репетитор английского

Интерактивный квест-репетитор английского языка для детей 9-11 лет.

## 🚀 Быстрый старт (через GitHub Pages)

### Шаг 1: Создайте репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт
2. Нажмите кнопку **"New"** (зелёная, вверху слева)
3. Заполните:
   - **Repository name**: `neon-english-tutor`
   - **Description**: `Квест-репетитор английского языка`
   - Выберите **Public**
   - ✅ Поставьте галочку **"Add a README file"**
4. Нажмите **"Create repository"**

### Шаг 2: Загрузите код в репозиторий

**Вариант А: Через веб-интерфейс (проще)**

1. В созданном репозитории нажмите **"Add file"** → **"Upload files"**
2. Перетащите все файлы проекта (кроме папки `node_modules` и `dist`)
3. Нажмите **"Commit changes"**

**Вариант Б: Через Git (если умеете)**

```bash
cd "C:\Users\Александр Маракушин\Репетитор по английскому\workspace"
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/neon-english-tutor.git
git push -u origin main
```

### Шаг 3: Включите GitHub Pages

1. В репозитории перейдите в **Settings** (вкладка вверху)
2. В левом меню выберите **Pages**
3. В разделе **"Build and deployment"**:
   - **Source**: выберите **"GitHub Actions"**
4. Готово! GitHub автоматически соберёт и задеплоит сайт

### Шаг 4: Откройте сайт

Через 1-2 минуты после первого push сайт будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/neon-english-tutor/
```

Например: `https://ivanov.github.io/neon-english-tutor/`

## 🔄 Обновление сайта

Просто загрузите новые файлы в репозиторий — GitHub автоматически пересоберёт и обновит сайт через GitHub Actions.

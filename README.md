# Neon English — квест-репетитор английского

Интерактивный квест-репетитор английского языка для детей 9–11 лет.
Клиентское SPA: React 18, TypeScript, Vite 6, Tailwind CSS 4. Без бэкенда: прогресс хранится в `localStorage` браузера. Чат с роботом Вольтом — локальный словарный наставник, без облачного LLM.

## Возможности

- 6 тематических планет с уроками и боссами
- Робот-наставник Вольт
- Голосовое произношение (Web Speech API) и упражнения на слух
- Разговор с Вольтом: повтор английских фраз в микрофон и оценка произношения (лучше всего в Chrome или Edge)
- Интервальные повторения слов (SRS)
- Стартовый тест, который открывает планеты и выдаёт XP
- Автосохранение прогресса в этом браузере, плюс скачать/загрузить JSON в настройках
- Магазин Вольта: запасное сердце за вольты
- Достижения по имени, словарь с эмодзи, ссылки `#/map`, `#/chat`, `#/progress`

Облачный ИИ-чат (ключи OpenAI/Yandex в браузере) **не подключён**: ключ LLM нельзя держать на клиенте. Когда появится серверный прокси, его можно будет вернуть отдельно.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте **http://localhost:3000/neon-english-tutor/** (базовый путь такой же, как у GitHub Pages).

Другие команды:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Деплой на GitHub Pages

Репозиторий уже настроен: GitHub Actions (`lint` → `typecheck` → `test` → `build` → Pages) публикует сайт при пуше в `main`.

Адрес:

```
https://<логин>.github.io/neon-english-tutor/
```

Если имя репозитория другое, поменяйте `base` в `vite.config.js`.
